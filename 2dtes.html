SISWA DI SEKOLAH

    PETUNJUK KONTROL & MULTIPLAYER

    ⌨️ Keyboard (PC): Gunakan WASD atau PANAH untuk bergerak.

    💬 Obrolan Chat: Tekan ENTER untuk mulai mengetik chat. Saat kolom chat aktif, pergerakan karakter dinonaktifkan sementara. Tekan ENTER lagi untuk mengirim pesan dan kembali mengontrol karakter.

    📱 Mobile / Touchscreen: Gunakan Virtual D-Pad di kiri bawah layar.

    🌐 Cara Terhubung dengan Teman:

    • Uji Coba Lokal: Buka link game ini di 2 tab browser berbeda di komputer yang sama. Karakter akan langsung terhubung secara otomatis!
    • Main Online di HP/PC Lain: Klik tombol Config Firebase di menu depan dan tempel JSON Firebase Project milikmu. Semuanya langsung terhubung secara live.
