Menyusun urutan instruksi atau langkah logis bertahap untuk menyelesaikan masalah.

Definisi & Asal Usul Istilah Algoritma

Definisi: Algoritma adalah urutan dari sejumlah langkah logis dan sistematis yang disusun untuk memecahkan suatu masalah tertentu, yang dapat dijalankan oleh manusia maupun oleh komputer.
Asal Usul: Istilah ini berasal dari nama matematikawan terkemuka Mohammad bin Musa al-Khwarizmi (780–850). Algoritma dapat disajikan dalam narasi, pseudocode, atau flowchart.

3. Struktur Percabangan & Pengulangan

Branching & Looping (Percabangan & Perulangan)

Struktur kontrol memungkinkan program mengambil jalur eksekusi berbeda berdasarkan kondisi logis (*if-elif-else*) atau mengulang blok kode secara efisien (*for* dan *while*).

A. Percabangan (*Branching / Nested If*)

Digunakan untuk menyeleksi multi-kondisi bertingkat. Contoh skrip Python untuk penentuan predikat nilai rapor: 

nilai = 75

if nilai >= 80:
    print("Predikat A")
elif nilai >= 70:
    print("Predikat B")
else:
    print("Predikat C")

Output: Program mencetak "Predikat B" karena nilai 75 memenuhi syarat `>= 70` tetapi tidak mencapai `>= 80`.

B. Perulangan (*Looping / For & While*)

Digunakan untuk mengulang instruksi secara otomatis. Python mendukung perintah `for` dan `while` bersarang (*nested loop*): 

# Perulangan For
for i in range(3):
    print("Iterasi ke-", i)

# Perulangan While
j = 0
while j < 2:
    print("While ke-", j)
    j += 1

Kegunaan: Sangat efektif untuk pengolahan data array, matriks dua dimensi, dan pelatihan model Machine Learning sederhana.
