3. Struktur Percabangan & Pengulangan + Analogi Excel

Branching & Looping Dihubungkan dengan Microsoft Excel

Konsep pemrograman seperti branching (percabangan) dan looping (perulangan) memiliki padanan intuitif yang sering digunakan dalam kehidupan sehari-hari saat mengolah tabel di Microsoft Excel menggunakan rumus logika (`IF`, `IFS`) dan fitur Fill Handle.

A. Percabangan (*Branching / If-Else*)

Dalam koding, percabangan menguji suatu kondisi benar atau salah. Di Microsoft Excel, hal ini setara dengan penggunaan fungsi `=IF()` atau `=IFS()`.

Python (Koding): 
nilai = 75
if nilai >= 80:
    print("Predikat A")
elif nilai >= 70:
    print("Predikat B")
else:
    print("Predikat C")
Analogi Microsoft Excel (Formula): 
=IFS(A2>=80; "Predikat A"; A2>=70; "Predikat B"; TRUE; "Predikat C")

Penjelasan: Excel memeriksa nilai di sel `A2`. Jika ≥ 80, bernilai "Predikat A"; jika ≥ 70, bernilai "Predikat B"; selain itu "Predikat C". Ini persis logika if-elif-else!

B. Perulangan (*Looping / For & While*)

Dalam koding, perulangan menjalankan instruksi berkali-kali tanpa menulis kode berulang. Di Microsoft Excel, analoginya adalah fitur Fill Handle (Tarik Rumus ke Bawah) dan Tabel Otomatis yang mengevaluasi ratusan baris data secara instan.

Python (Koding): 
# Mengulang perhitungan pajak untuk 5 baris data
for i in range(5):
    pajak = gaji[i] * 0.10
    print("Pajak ke-", i, "=", pajak)
Analogi Microsoft Excel (AutoFill): 
=B2 * 0.10  (lalu ditarik ke bawah dari baris 2 sampai 100)

Penjelasan: Alih-alih menulis rumus satu per satu untuk 100 karyawan, pengguna Excel menulis satu rumus lalu menarik ke bawah (iterasi baris otomatis), mirip konsep for loop pada array/tabel.
